A custom implementation of the classic card game **UNO**, built in Python featuring a graphical interface and an AI opponent.
## 🚀 Features
* **Full Game Logic:** Turn-based gameplay adhering to standard UNO rules (color matching, number matching, special action cards).
* **AI Opponent:** An integrated AI that evaluates the current game state and makes strategic moves.
* **Graphical Interface:** Visual representation of player cards, the discard pile, and turn indicators.
## 🛠️ Tech Stack
* **Language:** Python 3
* **Interface / GUI:** Pygame / GUI framework
* **Architecture:** Object-Oriented Programming (OOP) for cards, deck, players, and game state management.
